Coverage notes:

- Azure Policy is the primary documentation set. Its repeated rows cover distinct concerns: regulatory initiatives, effects, remediation, exemptions, reporting, and policy as code.
- Download Azure Policy first, then Microsoft Defender for Cloud and Cloud Adoption Framework. Add Microsoft Purview for assessment, evidence, auditor, Microsoft 365, or organization-wide compliance requirements.
- Azure Policy enforces and corrects Azure resource configurations; Defender for Cloud assesses and reports posture; Purview Compliance Manager manages assessments, evidence, owners, and improvement actions; Azure compliance offerings document Microsoft's certifications and audit scope.
- Use Azure Machine Configuration when the requirement concerns guest operating system settings. Standard Azure Policy evaluates Azure Resource Manager properties, not in-guest configuration.
- Azure Management Groups provide policy inheritance at scale. Azure Resource Graph, Azure Monitor, and Azure Arc are supporting topics for reporting, alerting, and hybrid or multicloud coverage.
- Azure Blueprints appears in older material but is retiring; prefer current policy, infrastructure-as-code, deployment-stack, and template-spec patterns where applicable.
