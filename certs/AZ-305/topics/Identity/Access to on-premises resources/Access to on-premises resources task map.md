Coverage notes:

- Coverage is fragmented across several documentation sets. Application proxy is the primary set for remote web applications, but a complete design can also require Private Access, AD DS authorization, hybrid group provisioning, application provisioning, and identity governance.
- Read the scenario for the resource type: use Application Proxy for web applications, Private Access for broader TCP or UDP resources, AD DS or Domain Services for legacy Kerberos, NTLM, or LDAP requirements, and Azure Arc-enabled servers when the target is an on-premises server itself.
- Download Application proxy, Global Secure Access, Active Directory Domain Services, Hybrid identity, and Microsoft Entra ID Governance first. Add Domain Services when the scenario requires managed legacy domain capabilities.
- Separate four decisions: who can reach the resource, how the user authenticates, what the back-end resource authorizes, and how access is requested, reviewed, and removed. Application Proxy or Private Access secures the path but does not replace fine-grained back-end authorization.
- Match Application Proxy SSO to the back end: use Kerberos constrained delegation for Integrated Windows Authentication, and use SAML, header-based, or password-based SSO only when the application supports or requires that method.
- Microsoft Entra Cloud Sync can provision governed group membership back to AD DS, while application provisioning creates and removes accounts or entitlements in the target system. Entitlement management and access reviews add approvals, expiration, recertification, and revocation.
- Network connectivity is not authorization. VPN Gateway and ExpressRoute provide reachability; per-user, per-app, MFA-enforced, and auditable access requires identity and application controls such as Application Proxy, Private Access, Conditional Access, groups, and ACLs.
- Architecture guidance is especially useful for the recommendation wording. The Well-Architected Framework and Entra resilience guidance explain least privilege and availability tradeoffs, while product pages explain the individual capabilities.
- Azure Files identity-based SMB access, AD FS migration, cloud Kerberos trust, hybrid device identity, Private Access for domain controllers, PIM for Groups, Defender for Cloud Apps session controls, and Azure Bastion are adjacent topics that should not dominate this map.
