Coverage notes:

- Azure Key Vault is the primary documentation set, but the task spans service selection, workload identity, cryptographic custody, lifecycle operations, network and access controls, governance, monitoring, and resilience.
- Download Azure Key Vault first. Then prioritize Azure security fundamentals for product selection, Azure Key Vault Managed HSM for regulated or single-tenant HSM scenarios, Managed identities for secretless access, and the Azure Well-Architected Framework for the architecture decision process.
- Match the object to the requirement: use secrets for sensitive opaque values, keys for cryptographic operations and customer-managed encryption, and Key Vault certificates for X.509 lifecycle management. Managed HSM stores only HSM-backed cryptographic keys, not secrets or certificates.
- Prefer eliminating credentials through managed identities when the target supports Microsoft Entra authentication. When a credential remains unavoidable, use the managed identity as the bootstrap identity that retrieves it from Key Vault.
- Prefer Azure RBAC over legacy access policies, grant workloads only the object operations they require, separate vaults by application, environment, region, or tenant boundary as appropriate, and use PIM for privileged human administration.
- Design the complete lifecycle: automate rotation or renewal, use versionless identifiers where consumers support automatic adoption of new versions, monitor expiry and change events, audit access, and retain old key versions until dependent data has been rewrapped or migrated.
- Enable soft delete and purge protection, understand automatic zone and regional redundancy, and back up irreplaceable objects. Recovery controls do not replace application retry, caching, throttling, or regional dependency planning.
- Azure Cloud HSM and Azure Payment HSM may be testable when the scenario requires customer-controlled general-purpose HSMs or payment-card cryptography. Azure App Configuration references, App Service and VM certificate delivery, AKS CSI integration, Defender for Key Vault, Event Grid, and Azure Policy are relevant integration and governance topics but are covered more lightly than the core service-selection sources.
